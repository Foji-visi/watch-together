# Вдвоём — совместный просмотр с чатом

Ты кидаешь ссылку на видео — оно включается у вас обоих. Пауза, воспроизведение и перемотка у одного сразу повторяются у другого, а если кто-то отстал, плеер сам его подтягивает. Справа (на iPhone — снизу) чат.

## Какие ссылки работают

Работают ссылки на YouTube, Rutube и VK Видео (VK — экспериментально), прямые ссылки на видеофайл (`.mp4`, `.webm`) и на поток `.m3u8`, а ещё фильмы, которые лежат у тебя в папке `videos`.

Не работают Netflix, Кинопоиск, Okko и другие платные сервисы (у них защита от копирования; Rave договаривается с ними отдельно), а также обычные ссылки на страницу сайта с фильмом или дорамой. Страница — это не видео: внутри неё чужой плеер, которым управлять нельзя.


### Rutube и VK Видео

Вставляй обычную ссылку на видео, например `https://rutube.ru/video/…/` или `https://vkvideo.ru/video-123_456`.

- Реклама у каждого своя. Пока у одного идёт реклама, синхронизация ждёт, а после рекламы плеер сам догонит другого.
- Если VK пишет «VK Видео не отвечает» или видео не открывается, нажми в VK под видео «Поделиться» → «Экспортировать», скопируй код для встраивания целиком и вставь его вместо ссылки. В этом коде есть ключ доступа, без которого VK показывает не все видео.
- Видео с ограничением 18+ или только для подписчиков встроить нельзя — это ограничение самих сайтов.

### Как достать прямую ссылку с сайта

1. Открой страницу с фильмом в Chrome на ноутбуке и нажми F12.
2. Перейди на вкладку **Network**, в поле фильтра напиши `m3u8` (или `mp4`).
3. Включи видео на сайте. В списке появится строка — нажми на неё правой кнопкой → **Copy → Copy URL**.
4. Вставь эту ссылку в «Вдвоём».

Получается не всегда: некоторые сайты выдают ссылки, которые живут несколько минут или работают только на их собственной странице. Если не вышло — проще скачать фильм и положить его в папку `videos`.

## Запуск

1. Установи Node.js (версия LTS) с сайта nodejs.org.
2. Распакуй архив, открой папку `vdvoem`, кликни в адресную строку Проводника, напиши `cmd` и нажми Enter.
3. В открывшемся окне один раз выполни:
   ```
   npm install
   ```
4. Дальше каждый раз запускай так:
   ```
   npm start
   ```
5. Открой в браузере `http://localhost:3000`.

Если Windows спросит про брандмауэр — разреши доступ.

## Как подключить её

**Если вы в одной Wi-Fi сети.** При запуске сервер пишет адрес вида `http://192.168.x.x:3000`. Открой его на iPhone в Safari.

**Если вы в разных местах.** Нужен туннель — он даёт ноутбуку временный адрес в интернете. Бесплатно и без регистрации:

1. Один раз установи cloudflared. В новом окне `cmd`:
   ```
   winget install --id Cloudflare.cloudflared
   ```
2. Пока работает `npm start`, открой ещё одно окно `cmd` и выполни:
   ```
   cloudflared tunnel --url http://localhost:3000
   ```
3. В выводе появится адрес вида `https://что-то-там.trycloudflare.com`. Открой его, нажми «Пригласить» — ссылка на комнату скопируется — и отправь её ей.

Адрес туннеля меняется при каждом запуске, а ноутбук должен быть включён, пока вы смотрите. Сам ты можешь открыть ту же комнату через `http://localhost:3000/?room=КОД` (код — из ссылки), так быстрее.

## Выложить как сайт на Render

Тогда у сайта будет постоянная ссылка, и ноутбук с туннелем не нужны.

### 1. Залить проект на GitHub
1. Зарегистрируйся на github.com, нажми **+ → New repository**, придумай имя (например `vdvoem`), оставь **Public** или выбери **Private**, нажми **Create repository**.
2. На странице репозитория нажми **uploading an existing file**.
3. Перетащи в окно: `server.js`, `package.json`, `README.md`, `.gitignore` и папку `public` целиком (вместе с `index.html` внутри).
   Не загружай `node_modules`, `cloudflared.exe` и фильмы.
4. Нажми **Commit changes**.

Файл `.gitignore` в Проводнике может быть не виден, потому что имя начинается с точки. Если не найдёшь его — не страшно, просто не загружай лишнего.

### 2. Подключить Render
1. Зарегистрируйся на render.com через GitHub.
2. Нажми **New → Web Service** и выбери свой репозиторий.
3. Заполни:
   - **Language / Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. Нажми **Create Web Service** и подожди пару минут, пока в журнале не появится «Вдвоём» запущено.
5. Вверху страницы будет ссылка вида `https://vdvoem-xxxx.onrender.com` — это твой сайт.

### Как обновлять
Замени файл в репозитории на GitHub (открой файл → значок карандаша, или **Add file → Upload files** с тем же именем) и нажми **Commit changes**. Render сам заметит изменение и через пару минут перезапустит сайт.

### Что отличается от запуска дома
- Список «С ноутбука» и прокси для `.m3u8` на сайте выключены. YouTube, Rutube, VK и прямые ссылки работают как обычно.
- На бесплатном тарифе сервер засыпает, если на сайт долго никто не заходит. Первый заход после этого грузится около минуты.
- При перезапуске сервера пропадает история чата. Ссылки на комнаты продолжают работать.
- Дома всё работает по-прежнему: `npm start` + туннель.

## Фильмы с ноутбука

Положи файл в папку `videos` и обнови страницу — появится список «С ноутбука».

- Для iPhone нужен `.mp4` (видео H.264, звук AAC). Файлы `.mkv` iPhone не играет — переделай их бесплатной программой HandBrake (пресет «Fast 1080p30»).
- Видео идёт к ней с твоего интернета, поэтому важна скорость **отдачи**: для 1080p нужно примерно 5–8 Мбит/с, для 720p — 3–4.

## Советы для iPhone

- Нажатие «Войти в комнату» нужно, чтобы Safari разрешил звук. Если видео всё равно стоит — нажми «Подключиться к просмотру».
- В полноэкранном режиме iPhone чат не виден. Удобнее повернуть телефон и смотреть без полного экрана.
- Если ты открыл сайт по `https://`, ссылки на видео тоже должны быть `https://` — иначе браузер их заблокирует.

## Как это устроено

`server.js` хранит для каждой комнаты, какое видео включено, играет ли оно и с какой секунды, и рассылает это всем через Socket.io. Страница `public/index.html` сверяет свой плеер с этим состоянием каждую секунду: небольшое отставание выравнивает ускорением на 5%, большое — перемоткой. Если сайт не отдаёт `.m3u8` браузеру на компьютере напрямую, плеер пробует загрузить его через ноутбук (`/proxy`).
